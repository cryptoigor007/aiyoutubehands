# Безопасная работа с YouTube API (анти-бан)

Обязательно для оператора и AI-агентов. См. также `docs/AGENT_PROMPT_PROCESS.md`.

## Что делает `ayh process` с API

| Этап | Запросы | Запись на канал? |
|------|---------|------------------|
| analyze | channels.list, playlistItems.list, videos.list (пачками ≤50), playlists.list + items (membership) | **Нет** |
| apply | videos.update (50), thumbnails.set (50), опционально playlistItems.insert (50) | **Да**, только по плану |

Локальные файлы Shorts Maker: **только чтение**. Пишутся лишь:

- `~/.config/aiyoutubehands/processed.db`
- `~/.local/state/aiyoutubehands/ayh_run_*.log`
- описание на YouTube (маркер `#ayh_processed`)

## Как не словить бан / квоту

1. **Сначала всегда analyze**, смотрите таблицу и сумму квоты.
2. **apply только** после фразы `подтверждаю план от ДД.ММ.ГГГГ`.
3. Не гоняйте apply пачками вручную в обход process.
4. При **403 / 429** — **стоп на день**, не повторять.
5. Между write — пауза ≥ 0.75 с (встроена в processor).
6. Один `videos.update` на видео (title+description+tags вместе).
7. Не трогайте public/unlisted и ролики **с просмотрами** — process их пропускает.
8. Суточный лимит API: 10 000 units. update/thumbnail = 50 каждый.

## Дубликаты папок и неоднозначный matching

Если в Shorts Maker две папки с одним очищенным title или несколько видео с одной длительностью:

- в плане статус **`пропуск: дубликат папки`** / **`неоднозначный title`** / **`неоднозначная duration`**;
- указаны **связанные папки и/или video_id**;
- **автоприменения нет** — разберите вручную (переименуйте папку, оставьте одну, укажите id в файле).

## Только новые загрузки

В план «к обработке» попадают видео, которые одновременно:

- **private**;
- без просмотров (viewCount = 0 или нет статистики);
- за горизонт `--days` (по умолчанию 14);
- не `#ayh_processed` / ledger;
- не «уже оформлено»;
- не дубликат / не неоднозначный match.

## Чеклист перед apply

- [ ] План просмотрен, дубликаты понятны  
- [ ] Квота `would_exceed=false`  
- [ ] Нет чужих public-роликов в «к обработке»  
- [ ] Точная фраза подтверждения с сегодняшней датой MSK
