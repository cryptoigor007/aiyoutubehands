## 5. Теги и хештеги

**Базовые теги (всегда):**
```
психология отношений, современное общество, психология личности, точка наблюдения
```

**Хештеги в описании:** 7 штук — тема + канал. Больше 15 YouTube игнорирует целиком.

## 6. Правила безопасности

1. **Не трогать ролики, которые набирают 5+ просмотров в день** — смена метаданных может прервать волну показов.
2. **Обложки не трогать, если стоят** — `thumbnails.set` не вызывается.
3. **Доступ — только «ограниченный» (private).** При правках невышедших видео `privacyStatus` всегда `private`; никогда public/unlisted до срока. `publishAt` ставится только для private + ни разу не опубликованных; после публикации время вернуть нельзя (ограничение платформы). В каждом плане — явный пункт про доступ; после записи — проверка `privacyStatus` и `publishAt` через `videos.list`.
4. **Служебные поля сохранять** — `embeddable`, `publicStatsViewable`, `selfDeclaredMadeForKids`. `videos.update` заменяет блок `status` целиком, непереданные поля сбрасываются.
5. **Перед записью — копия** текущих значений в JSON-файл.
6. **Остановка на первой ошибке** — не продолжать после 403/429.
7. **Пауза 0.8 с** между записями.

1. **Мусор в описании** у «Почему нас так бесят чужие недостатки?» — огрызок «Почему ты всё тянешь сам? Описание:». Ролик активный, поэтому не трогал.
2. **Ссылки на плейлисты** обрезаны до 12 символов во всех сериях — вероятно, не открываются. Нужны настоящие ID.
3. **Длинные видео не смотрят** — у пяти серий 0–9 просмотров при сотнях у шортсов.
4. **Ш61–Ш100** — на канал не загружены, ждут.

## 10. Записи (community posts)

См. полный документ: [`docs/POSTS.md`](POSTS.md).

Кратко:

```bash
ayh post create --text-file post.txt          # dry-run
ayh post create --text-file post.txt --image img.jpg --no-dry-run --yes
```

Только macOS + Safari (Allow JavaScript from Apple Events).  
Картинка: при неудаче прикрепления — стоп, без молчаливой публикации без неё.  
Подтверждение — по общим правилам репо (фраза с датой и hash плана).
