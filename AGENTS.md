# Правила работы с YouTube API

Канал: `UC…pcA` (полный ID лежит в `config/local.yaml` → `youtube.expected_channel_id`,
в git не выносится). Дневная квота — 10 000 юнитов.

Этот файл подхватывается автоматически. Правила обязательны для любой сессии
и любого агента в этом репозитории.

## Тарифы (проверено по документации Google)

| Операция | Юниты |
|---|---|
| `videos.list` | 1 |
| `playlists.list` | 1 |
| `playlistItems.list` | 1 |
| `channels.list` | 1 |
| `videos.update` | 50 |
| `thumbnails.set` | 50 |
| `videos.delete` | 50 |
| `playlists.insert/update/delete` | 50 |
| `comments.insert` | 50 |
| `captions.insert` | 400 |
| `videos.insert` | 1600 |
| `search.list` | 100 |

`videos.list` принимает до **50 ID через запятую за 1 юнит** — проверяй пачкой,
а не по одному.

## Правила квоты

1. **Один вызов на видео.** Заголовок, описание, теги и приватность меняются
   одним `videos.update` с `part=snippet,status`. Не дроби на 4 прохода.
2. **Сначала собери все данные, потом пиши.** Никаких «записал одно, пошёл
   проверять, записал второе».
3. **Пауза ≥ 0.5 с между write-вызовами.** На 11 видео это +5 секунд.
4. **Стоп на первом 403/429.** Не ретраить пачками. Частичный прогон лучше
   полного бана.
5. **`videos.delete` — только по письменной команде автора.** Необратимо.
6. **`privacyStatus` меняется только с явного согласия** — требование
   YouTube Developer Policies.
7. **Не заливать обложки, если они уже верны.** `thumbnails.set` — это 50
   юнитов на видео, а обложку нельзя поменять в `videos.update` в принципе.
   Сначала сверь текущую через OCR, потом решай, надо ли перезаливать.

## Грабли, на которые уже наступали

### `publishAt` нельзя поставить на опубликованное видео

Документация `videos.update`, поле `status.publishAt`:

> This property can only be set if the video's privacy status is private
> **and the video has never been published**.

YouTube отвечает `400 invalidPublishAt` (`location: body.status.publishAt`),
если у видео непустой `snippet.publishedAt`. Это **ограничение платформы**:
ни формат даты, ни повторы, ни сдвиг часового пояса не помогут. Видео,
загруженное и переведённое в `unlisted`, уже считается опубликованным.

Отсюда: расписание для таких роликов ставится **только вручную в YouTube Studio**.
`schedule_video()` в `youtube.py` годится лишь для свежих вставок.

### Не проверяй обложку по `i.ytimg.com/vi/<id>/maxresdefault.jpg`

Для вертикальных обложек (9:16) эта ссылка **без подписи** отдаёт заглушку
120×90 (~1 КБ), даже когда обложка загружена и корректна. Это выглядит как
«обложки нет» и вводит в заблуждение.

Правильно: брать `snippet.thumbnails` из `videos.list` — там уже подписанные
URL. Или использовать подписанную ссылку из ответа `thumbnails.set`.

Признак заглушки: ровно **1097 байт** и размер **120×90**.

### Теги применяются асинхронно

`videos.update` отвечает эхом с посчитанными тегами, но на YouTube они
проявляются не сразу. Чтение сразу после записи может вернуть пустой список —
это не потеря данных. Перед тем как перезаписывать, **подожди и перечитай**.

### Ответ на запись — не проверка

Всегда проверяй свежим `videos.list`. Сравнивай теги как **множества**:
YouTube не сохраняет их порядок и возвращает перемешанными.

### Граница сброса квоты — тихоокеанское время

YouTube сбрасывает квоту в 00:00 PT, а не UTC. `QuotaLedger._today()` считает
день по `America/Los_Angeles`. Читать леджер в окне 03:00–10:00 MSK, когда
UTC ещё «вчера», бессмысленно.

## Правильная последовательность

1. Собрать все данные локально, проверить длины (title ≤ 100, description ≤ 5000,
   tags ≤ 500) и отсутствие мусора в описании.
2. Одним `videos.list` сверить текущее состояние и сопоставить ID с папками.
3. Прогнать `dry_run=True`, посмотреть тело запроса.
4. Записать, пауза 0.5 с, стоп на первой ошибке.
5. Подождать, перечитать `videos.list`, убедиться что всё сошлось.

## Ошибки, которые сервис скрывает

`map_http_error()` обрезает тело ответа до 200 символов. При `400` не видно
`errors[0].reason`. Чтобы увидеть полный ответ, перехвати `httpx.Client.request`
и напечатай `resp.text` — это дешевле, чем гадать о причине.
